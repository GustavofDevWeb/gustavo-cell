# 📱 Gustavo Cell

Sistema web desenvolvido para auxiliar no gerenciamento de uma loja e assistência técnica de smartphones.

Este projeto foi criado com o objetivo de colocar em prática meus conhecimentos em desenvolvimento web e, ao mesmo tempo, desenvolver uma solução para necessidades reais do dia a dia de uma assistência técnica.

## 🚀 Funcionalidades

- 📦 Gerenciamento de produtos
- 📊 Controle de estoque
- 🛒 Sistema de vendas e carrinho
- 🔧 Gerenciamento de serviços
- 💰 Controle de dívidas de clientes
- ⚠️ Alertas relacionados ao estoque
- 💾 Área de backup
- 🔎 Pesquisa e organização de produtos

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

### 🔧 Ferramentas

- Git
- GitHub

## 📚 Objetivo do projeto

O Gustavo Cell também faz parte do meu processo de aprendizado em desenvolvimento Front-End.

Durante a evolução do projeto, estou aprofundando meus conhecimentos em:

- JavaScript
- Manipulação do DOM
- Responsividade
- Git e GitHub
- Organização e manutenção de projetos web

## 💻 Como executar

O projeto utiliza HTML, CSS e JavaScript e pode ser executado diretamente no navegador.

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `Index.html` no navegador.
